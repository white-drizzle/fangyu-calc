# 制造企业综合公式计算器

企业运营虚拟仿真（方宇平台）制造企业角色的辅助计算网页。

## 打开方式

直接访问 Pages 站点首页即可，无需下载：

```
https://white-drizzle.github.io/fangyu-calc/
```

页面是**单文件、零外部依赖**的（无 CDN、无图片、无 fetch/XHR），
手机上打开也能正常用。想离线使用就 `Ctrl+S` 存成 HTML，双击即可。

## 覆盖范围

7 个标签页：建厂 / 生产 / 仓储 / 研发 / 广告 / 财务 / 市场。

| 标签页 | 功能 |
|---|---|
| 建厂 | 厂区扩建面积与费用 |
| 生产 | 产线兼容判定、理论最大产量与细化产量、最优人员配备反推、材料/人工/库存成本、毛利润 |
| 仓储 | 吞吐量消耗与剩余量、入出库判定 |
| 研发 | 项目自动带参、成功率区间、推荐研发人数 |
| 广告 | 广告有效性校验、市场开拓门槛判定 |
| 财务 | 贷款与四期现金流 |
| 市场 | 产品经济性对比、市场需求 |

**未集成**：竞单定价评分（评分模型已确认与手册不同，以客户课程为准）。

## 参数方案

页面内置三套参数，可切换：

- **默认（软件手册 2.0/3.0）** —— L 4000 / H 6000 / O 8000 / S 10000
- **江汉大学（202609）** —— L 4000 / H 8000 / O 10000 / S 12000，8 季度制
- **自定义** —— 5 个输入框可编辑，改完自动重算全部最优方案

· 差值 = 0 时系统按 0.5 计算（平台规则第 10 页注），故默认取「按 0.5×产能」；差值 < 0 则无法生产。

库存持有成本 = 期末库存数量 × 单位库存成本。（手册 §2.5 / §3.1：按期末库存数量计算、下一期支付；产成品 L型 100 元/件·季、H/O/S 型 150 元/件·季，原材料 50 元/件）
最优人员配备由公式反推，不再依赖手抄表：在「产能 =（初级能力×人数 + 高级能力×人数）×(1 + 管理能力×人数)×人员使用率」达到该线最大产能的前提下，取工资最低的整数组合（手册 §2.1 第 4 条：产能达上限后不再增加，故超额配备只是白付工资）。点「按公式反推最优配备」会同时带入人数与当季人工工资（工资 = 初级×4000 + 高级×6000 + 管理×5000）。

竞单定价

竞单只比总分，总分最高的拿走订单。四个分项里只有价格分由咱们的报价决定，其余三项这一期是固定值 —— 所以定价的本质是：在「总分刚好超过对手」的前提下，把价格报到尽可能高。
评分规则（客户课程 PPT）：最终得分 = 市场影响力分 + 价格分 + 认证分 + 永久占有加分； 价格每高于标底价 1% → −10 分，每低于标底价 1% → +2 分（标底价 = 该产品型号的售价，1% 即步长）。
⚠️ 取整口径尚未定论：档位边界落在哪，决定最高能报到多少，两说相差半个步长（标底 4000 时 = 20 元）。
· 整档跳变（默认，与原程序一致）：档位在 标底价 + k×步长 处跳变 → 最高价 = 标底价 + (N+1)×步长 − 1
· 半档跳变（来自 竞价说明.xlsx E 列公式 ROUND(-((报价-标底价)/步长)*10, -1)）：在 标底价 + (k+0.5)×步长 处跳变 → 最高价 = 标底价 + (N+0.5)×步长 − 1
两者的安全方向不同：若实际是整档却按半档算，报价偏低（少赚，不会丢单）；若实际是半档却按整档算，报价偏高（可能丢单）。 建议在游戏里用同一组输入试两个价，看哪个掉档，即可一次定论。
「还需净胜」为正说明降价加分才追得上，为负说明可以涨价；「校验」显示 可拿下 = 这套报价严格超过对手， 分数不够 = 需要的价格分超过满分 100（这个单抢不到），报价为负 = 降到底也不够。
